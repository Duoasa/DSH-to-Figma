# 本地 Markdown 设计规范与默认规范

## 什么是规范

规范用于描述 UI 的布局、字号、字体、颜色、间距、圆角、组件状态和动效等设计规则。它不是插件发布计划或工程实现清单。示例：

```md
# 登录卡片规范
- 卡片宽度 360 px，内边距 24 px，垂直内容间距 16 px。
- 使用 Inter；标题 24 px，正文 14 px。
- 主按钮高 44 px，圆角 12 px，背景 #245BEB，文字白色。
- 文字可编辑，布局使用 Auto Layout。
```

## 导入

1. 保持 Figma 配套插件“已连接”。
2. 展开 **本地设计规范**，点击 **导入 Markdown**。
3. 选择 UTF-8 编码的 `.md` 或 `.markdown` 文件，单文件不超过 512 KiB。
4. 看到已导入提示后，在“已导入的规范”中检查名称。同名副本用短 ID 区分。

导入会创建独立副本，重复导入不会覆盖旧副本。每个 DSH home 最多 100 份。当前界面没有删除规范副本按钮，也没有自动监视原文件的功能。

## 设为默认、切换与清除

1. 在下拉列表选中一份规范。
2. 点击 **设为默认**。只有点击后才生效；单纯换下拉选项是选择操作对象。
3. “当前默认”显示规范名称，收起标题显示“默认已启用”。
4. 后续让 DSH 做本地 Figma 设计时，不用再说文件名。DSH 会检查并读取当前默认，按其中 UI 规则工作；本次用户明确要求优先。
5. 切换：选择另一份，点击“设为默认”。
6. 停用：点击 **清除默认**。默认选择移除，已导入副本仍保留，已有画布不会被撤销。

默认属于**当前 DSH 本机 home**，不是某个 Figma 文件或单个聊天。它会用于该环境后续本地 Figma 设计，跨文件使用前应留意规范是否适合。其他电脑或其他 DSH home 不会自动同步。

关闭插件、重启 DSH 后仍保留选择。切换/清除影响后续调用；已经开始执行的画布操作不会被中途取消。设置默认不会立即批量改造现有画板；需另行要求检查或修改。

## 自动遵循是怎么保证的

插件把当前默认身份和读取要求提供给 DSH，模型不必靠旧聊天记忆猜文件名。写入画布前，本地宿主会检查这个 Work 会话是否完整读取了默认规范的当前版本；分页没读完、切换默认、规范被修改后，都需要读取当前版本才能继续。默认文件丢失或损坏时提示重新选择/清除，不静默忽略。

这是**读取和版本检查**，并不是自动验证所有视觉规则的排版引擎。生成后仍应检查设计。可以说：“按默认规范检查这张卡片，列出不符合的地方并修正。”

## 保存与原文件的关系

| 动作 | 结果 |
| --- | --- |
| 删除桌面原 MD | 已导入副本和默认选择仍可用 |
| 修改桌面原 MD | 已导入副本不会同步变化；需要重新导入并明确切换 |
| DSH 修改导入副本 | 下次读取使用新版本；默认仍指向同一副本 |
| 清除默认 | 只停止自动应用，不删副本 |
| 清理 DSH 内的副本 | 该副本不可用；若它是默认，会提示重新选择或清除 |
| 换电脑或 DSH home | 不自动迁移；导出后在新环境导入并设默认 |

副本保存在 `<DSH_HOME>/figma/specs/`，默认选择保存在 `<DSH_HOME>/figma/specs-default.json`。不要让普通用户直接编辑内部 JSON；需要清理时先确认对象和备份，不要删除整个 figma 目录，那里还可能有配对及授权状态。

## 修改和导出

对 DSH 说：“把默认规范中的按钮圆角从 12 px 改为 16 px，其他不变。”DSH 读取副本并做精确替换；如果内容被别人更新，或同一句出现多次，会先报冲突，不会部分覆盖。多页内容要完整读取，超长单行可能需要在源文件中分行后重新导入。

修改规范不自动修改画布。若也要更新设计，请明确说：“修改规范后，把选中按钮同步调整为 16 px。”

在下拉列表选中目标，点击 **导出所选规范**，通过下载/保存窗口获得最新 Markdown。导出不自动覆盖桌面原文件；取消保存不代表已写出文件。若需要覆盖原文件，应在保存时明确选择，不让 DSH 擅自覆盖。

## 与 Figma 原生 Specs 的区别

本地 Markdown 不是 Figma 原生 SPEC_BLOCK 文档，不会自动出现在 Figma 云端 Specs，不提供原生评论、多用户协作或云端规范链接。原生 `figma.spec` 必须由实际编辑器开放；本地环境未开放时使用 Markdown 替代，不把普通文本画板伪装成原生 Spec。

## 常见问法

- “当前默认是什么？请确认使用的是最新版本。”
- “默认规范里规定了哪些按钮和字体规则？”
- “本次只把按钮改红，其他继续按默认规范。”
- “原文件改了但生成结果没变，应该怎样更新导入副本？”
- “清除默认后，为什么原来的画板没有变回去？”

默认内容被 DSH 读取后可能进入所选模型服务的上下文。‘本机保存’不等于‘模型处理完全离线’。

## 副本损坏时

列表会继续显示正常规范，并提示不可读取的副本数量；损坏数据会保留，不会自动删除。可以重新导入原 Markdown，再设为默认，或先清除默认。损坏的默认在切换或清除前仍会阻止画布写入。保留的损坏副本也计入 100 份上限；需要清理时先备份并确认具体对象。
