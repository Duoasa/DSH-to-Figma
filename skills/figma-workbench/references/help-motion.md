# 动效、原型、FigJam 与 Slides

## 先检查当前编辑器能力

这些功能依赖 Figma 当前版本、文件类型和实际开放的 API。DSH 会针对目标查询能力：available 表示观察到接口，unavailable 表示未开放，unknown 表示尚不能确定。能力检测中的 `readOnly:true` 只说检测本身不写入，**不是整个插件只能读取**。

接口可读不证明所有写入都能成功；实际写入后的读回与播放验证仍然必要。不支持时应说明限制，不能造出相似但含义不同的内容冒充原生能力。

## 关键帧动画

可读取并在开放的 API 范围内修改位置、旋转、缩放、透明度、颜色、模糊等轨道，调整时长和缓动。目标通常应是顶层画板内的后代节点。

可说：“先检查选中方块的现有动效，把水平位移改为 0 到 240 px、时长 0.8 秒，保留颜色和模糊轨道。”

应保留未要求修改的轨道、关键帧和组件关系。把静态坐标改成新位置不等于创建了关键帧。某些轨道集合是只读视图，需要专用 API 修改；报只读集合错误不意味着完全不能编辑动效。

## 文字动画

在 TextStagger 等 API 可用时，可按字、词或文本结构应用文字进入效果，保留原生文字。可说：“让选中的英文字幕按词进入，总时长 1.5 秒，不拆成图片，也不要改文案。”具体分段及效果参数以编辑器实际支持为准。

## 动画样式和自定义样式

可查询开放的预设定义、应用样式，以及在支持的环境中创建或修改可复用的自定义动画样式。样式定义与应用到节点的那一次绑定有不同 ID。

本地替换 helper 仅支持最后一个样式绑定或最后一条自定义样式条目，避免无意改变顺序；返回新 ID。修改非最后一项需要明确保留顺序的重建方案，不能承诺无条件原位替换。失败可能产生部分修改，应先检查。

## 原型、播放和视频

原型触发器/跳转、关键帧时间轴和代码中的 CSS 动画是不同对象。用户说“动画”时，应据目标判断，不能把链接跳转当成关键帧实现。

静态 PNG 只能显示某一静态状态，不能证明动画节奏正确。完成后应在 Figma 时间轴/播放器中实际播放，或使用确实可用的导出能力。本地 `export_video` 可请求编辑器原生导出 MP4、GIF 或 WebM，并保存到工作区；是否能编码由实际编辑器决定，接口存在并不保证导出成功。不要把 PNG 改扩展名或描述成 MP4。递归动效读取还可生成有限范围的 CSS 候选，会列出不支持项；代码里的动画仍需项目运行验证。

## FigJam

先打开 FigJam 文件并运行配套插件。可用公开构造器创建便签、形状、文本、连线、分区或表格，保持可编辑。连接线应绑定到节点，移动后才能跟随。

可说：“在当前 FigJam 里画用户注册流程：填写资料、验证邮箱、成功；标出验证失败的返回路径。”

本地 `generate_diagram` 可接收结构化节点/连线，或有限的 Mermaid flowchart 语法，创建可编辑图形和绑定连线；它不是官方云端解析器，也不支持全部 Mermaid 图类型。Design 的组件构造器不能直接套到 FigJam；不要在不支持的编辑器里反复重试。

## Slides

先打开 Slides 文件。实际 API 可用时可以创建可编辑幻灯片、文字和形状，统一字号、留白、标题及页码，再检查代表页。

可说：“在当前 Slides 中做三页项目介绍：问题、方案、计划，采用一致的标题和版式。”

本地 `generate_deck` 提供标题、正文、演讲备注和配色主题的基础可编辑排版，并报告溢出；它不等于官方云端服务，也不保证所有模板、母版、转场或导出格式都能通过插件控制。新建云端演示文件与在当前文件添加幻灯片是不同步骤。
