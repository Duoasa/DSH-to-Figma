# 常见问题与排查

先回答用户的问题，再只查询解决该问题所需的状态。纯教程不要求先连 Figma。遇到故障可查 `figma_status({compact:true})`：当前 backend、DSH 插件版本、连接文档及 companionVersion、诊断信息。不能把磁盘上的包版本或窗口名称当成正在运行的版本。

## 连接与工具

| 现象 | 应检查什么 / 怎么处理 |
| --- | --- |
| 安装后 DSH 没有 Figma 工具 | 插件组件是否启用、是否运行；安装到了哪个 profile/home；重载组件，必要时重启 |
| 显示“等待 DSH 启动” | DSH 本地模式是否运行；是否同机；是否另一个宿主占用端口 |
| `bridge_port_in_use` | 找到占用同一桥接端口的重复宿主，确认后停用重复组件；不要随机终止不相关进程 |
| Figma 显示等待配对 / 密钥失效 | 使用当前 DSH 的 `figma_setup` 重新生成本机配对版；不要向聊天粘贴密钥 |
| 本地文档列表为空 | 在目标文件运行正确 home 对应的配套插件，保持窗口打开 |
| 要求 Work 会话 | 使用关联工作区的 DSH 会话；不是要求用户开启 Figma 开发者模式 |
| 多文件 / 旧绑定断开 | 列出当前连接，确认目标后明确绑定；不能悄悄改到另一个文件 |
| 官方 desktop 无法连接 | 在 Figma 开启官方桌面 MCP，并刷新连接；本地配套插件不能代替这个服务 |
| 远程注册 403 | 官方客户端/账号准入问题可能发生在授权前；不能用 Codex 已连接推断 DSH 已获准 |

保存的 bridge.json 或 CLI status 只能说明存在历史记录，不证明进程在线。未认证访问本地端点返回 401 是预期行为，不应据此关闭认证。

## 画布写入失败、超时或断线

若 `safeToRetryWithoutCanvasRead:true`，说明可修复执行前错误后重试；例如语法检查失败、已知不支持的同步 getter。若 false 或缺失，先检查画布和相关变量/组件，再决定补做，避免重复创建。

出现“执行中中断，操作不会重放”时：关闭并重新打开配套插件，确认目标文件，先读取可能受影响的节点。恢复连接不等于自动回滚。部分元数据查询（带 summary/分页/预算）不能解除不确定写入检查，需要对相关对象完整读回；不能拿无关节点的结果当作成功证据。

## 字体、素材、截图与性能

- 字体缺失：查实际可用字体和字重；用户同意替代后再换。不要私自转成图片。
- 素材路径被拒绝：素材工具只读当前 Work 工作区。检查真实路径，必要时经授权复制到工作区。
- 导出过大：拆批、降低倍率或缩小节点范围，不无限重试同一批。
- 模型看不到截图：检查当前模型是否支持图像输入；有导出文件不代表模型完成视觉检查。
- 大文件很慢：缩小页面/节点范围、复用已知 ID，避免反复扫描整个文件、列全量字体和截相同图片。
- 性能统计：插件统计的是当前 Work 会话内的画布调用，不是总 token、总任务耗时或全部工具次数；不能用它替代提供方账单。

## “只读”和不支持的 API

能力探测是只读的，不代表 local 插件禁止编辑。Motion 的某些集合不可直接赋值，需要专用方法。官方 desktop 模式以读取/截图为主；原生 Specs、云端视频、Code/Make 等需实际开放的 API 或官方工具。对不可用功能说明具体边界，不能通过改 capability 标志伪造支持。

## 用户可提供哪些诊断信息

插件版本、DSH 组件状态、当前 backend、文件类型、简短错误、发生前的操作、是否存在部分修改、相关节点 ID，以及不含秘密的界面截图。避免收集配对 code.js、配对 ZIP、bridge-token、OAuth 状态或整个用户配置目录。

回答示例：“当前是在 local 模式，但连接文档列表为空。请在目标 Figma 文件运行当前配对目录的 Local 插件；窗口显示已连接后，我再确认文件身份。无需复制密钥。”
