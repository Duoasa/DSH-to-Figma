# 设计、修改、素材与交付

## 如何描述需求

说明目标文件或选中对象、想改变什么、必须保留什么、期望尺寸/风格以及参考来源。需求有足够信息时，DSH 应直接执行；真正影响结果的未知项才需要询问。

示例：“在当前文件新增一张桌面端任务列表，宽 1200 px；复用现有颜色变量和按钮组件，不修改原画板。”

## 新建和编辑 UI

本地模式可在当前文件内创建/修改公开 Plugin API 支持的原生 Frame、文本、矢量、形状、Auto Layout、组件、实例和变量等。生成后应能在 Figma 中选择和编辑图层；图片素材本身仍是位图。

DSH 应先确认目标和必要属性，再修改并读回。视觉变化需要截图检查，变量绑定和组件关系需要结构检查。已有内容应按用户范围保留；遇到不支持的 API，不能偷偷改成截图或解除实例来“完成”。

可问：“只修改选中卡片的内边距为 24 px，不动文字和颜色。”
可问：“检查这张画板是否有溢出和不一致的间距，先列问题，不要修改。”

新建画板不等于创建独立云端 Figma 文件。本地工作流需要用户已打开一个文件；不要声称本地桥接提供云端新文件创建。

## 组件、变量和设计系统

- 可搜索文件内组件、样式和变量，创建组件/变体、使用实例、修改实例属性，并绑定颜色或其他支持变量的属性。
- 优先复用已有资源；不要因一次分页结果里没出现，就断言整个文件没有该组件/变量。
- 库访问受编辑器和账号实际能力限制；远程库不保证全部可列出或可编辑。
- 修改一个实例、修改主组件、解除实例是不同操作。用户只要求改文案时，不应解除组件关系。
- 原有组件代码链接保存于画布插件数据；新增 `project_mappings` 保存工作区中的显式映射。两者独立，均**不等于**发布官方 Code Connect。项目匹配候选还需要检查源码与实际效果。

可问：“把选中按钮改为‘立即开始’，保留主组件关系和变量绑定。”
可问：“检查本文件已有的颜色变量和模式，优先复用 Light/Dark；缺少模式时先单独尝试新增，遇到模式数量限制就说明可行的替代方案，保留现有 Light 值。”

已有多模式集合不代表当前还能新增模式。若 `addMode` 报 `Limited to 1 modes`，应按 [模式限制排查](help-troubleshooting.md#新增-dark-模式报-limited-to-1-modes) 先核对实际状态；独立单模式的深色变量集合需要重新绑定指定节点，不能只改现有 Light 值或声称实现了原生双模式切换。

## 字体和文字

Figma 必须能加载指定字体与准确字重才能编辑文字。缺字重时，应查询可用字体再与用户需求协调，不能悄悄把文本栅格化。中文字体和字符覆盖也需实际检查。可编辑文字不代表长文案必然不溢出，需要结合实际布局、约束、换行和尺寸检查。Auto Layout、固定布局、叠层和锁定都按用途使用，不以某种布局方式的占比衡量质量。

## 导入图片与 SVG

本地素材工具只读取当前 Work 工作区内的普通文件；符号链接也不能绕过真实路径限制。桌面文件如需作为设计素材，应先在用户授权范围内复制到工作区，或选择该工作区。

支持 PNG、JPEG、GIF、WebP 与自包含 SVG。SVG 可导入为可编辑矢量；位图作为图片填充导入，不自动变成原生组件。GIF 的导入不意味着保留或验证动画播放。外部链接、复杂 SVG 特性或字体效果须检查实际结果。

可问：“把工作区 assets/logo.svg 放到选中卡片左上角，保持比例。”

## 导出和截图

可按节点导出 PNG、JPG、SVG、PDF；具体格式仍取决于该节点是否可导出。批量一次 1–20 个节点，总返回数据有限制（12 MiB），太大时降低倍率、拆批或缩小范围。

文件保存在工作区的 `.figma/assets/<批次>/`，DSH 应返回实际文件路径，不能仅说“下载成功”。请求的路径不一定就是最终路径，应以工具返回为准。截图用于检查；不能因为有文件路径就说已经看过图片。模型没有图像输入能力时，可用结构结果，但需要明确未完成视觉检查。

## 设计转代码

DSH 可以读取设计结构、CSS/布局信息和图片，在当前项目里实现页面。这个工作由宿主模型和项目开发工具完成，桥接本身不把所有 Figma 功能一键无损转换为生产代码。应复用项目技术栈和组件，区分实际跑通的页面与静态草稿。

可问：“根据选中画板，用项目已有 React 组件实现页面，完成后运行项目现有检查。”

## 网页或截图复刻

本地 `capture_webpage` 可使用已安装的 Chrome/Chromium/Edge，在新的隔离浏览器中访问指定 HTTP(S) 页面，再导入有限的 DOM 样式和可编辑文字/盒子；也可直接提供 `import_dom_snapshot` 数据。它不会下载浏览器或借用已有登录状态。图片、视频、复杂效果、伪元素等可能只保留盒子或给出警告，响应式行为和业务逻辑不会自动迁移。应检查诊断并对比实际画面。

## 操作失败与撤销

普通画布脚本不是事务，失败可能发生在部分节点已经创建之后。`batch_edit` 仅对限定属性、简单文本或实色填充提供预检与尽力恢复，不能替代整个文档的事务或撤销。超时、断线或取消后，应先检查已变更对象再继续，不能无条件重放。不要自动撤销用户同时做的修改。需要回退时先明确哪些修改属于本次操作；也可由用户使用 Figma 自身的撤销/历史功能，但不能承诺一次撤销会精确对应全部多步任务。
