# DSH to Figma · 0.4.1

用自然语言读取、创建和修改 Figma 设计。默认通过本机插件连接，不消耗官方 Figma MCP 调用额度。

## 安装后的第一步

DSH 端安装完成后，把下面这句话发给 DSH：

> 帮我连接 Figma：调用 figma_setup 生成本机配对插件，给我 manifest.json 的完整路径；我运行插件后，用 figma_status 确认连接和两端版本，再读取选中的画板，不修改设计。

1. 在 Figma 桌面端先打开一个设计文件。
2. 选择 **Plugins → Development → Import plugin from manifest…**，导入 DSH 给出的 `manifest.json`。
3. 在目标文件中运行 **DSH to Figma · Local**，看到「已连接」后保持插件窗口打开。
4. 选中参考画板，回到 DSH 描述你的需求。多个文件同时连接时，明确要操作哪一个。

Figma 插件由 DSH 从内置代码生成，不需要另下 ZIP。通常位于 `~/.dsh/figma/companion/manifest.json`，以工具返回的实际路径为准。配对文件含本机凭证，不要上传或分享。

## 功能

- **画布读取**：选区、页面、图层、文字、尺寸、布局、样式与组件上下文；按名称、属性和页面查询。
- **UI 创建与编辑**：根据需求生成页面、参考截图复刻 UI、复用现有页面衍生新界面；支持原生节点与 JSON 场景导入。
- **布局与交互**：Auto Layout、固定尺寸与定位、约束、叠层、图层锁定及原型交互。
- **组件与设计系统**：组件、组件集、变体、实例属性和覆盖项；搜索并复用组件、样式与可访问的团队变量库。
- **变量与主题**：创建变量、增添模式、设置值与别名、绑定设计变量，读取依赖和模式信息。
- **设计参考**：绑定、换绑和解绑规范或画板；在插件中查看名称与缩略图，与 DSH 双向同步变更。
- **设计规范**：提取、保存和修改本地视觉规范；在编辑器提供接口时读写原生 Specs 文档与批注。
- **字体与图标**：字体查询、批量匹配与回退，内置常用矢量图标。
- **截图与参考图对照**：按需回图、尺寸控制、并排图、叠加图和像素/颜色差异；读取关键布局属性。
- **设计变更对比**：保存设计快照与基线，对照后续结构、样式及内容变化。
- **素材导入导出**：图片、SVG、图片填充替换；PNG、JPG、SVG、PDF 导出，原图提取及节点与文件映射。
- **原生动效**：关键帧、文字动画、动画样式与时间线编辑；读取动效并将部分属性转换为 CSS。
- **视频导出**：通过编辑器原生接口导出 MP4、GIF、WebM。
- **FigJam**：读取白板，创建可编辑的形状、文字和连接线；支持结构化图表与 Mermaid 流程图子集。
- **Slides**：在当前演示文件中生成可编辑幻灯片、标题、正文、主题布局和备注。
- **Shaders**：发现可用 Shader、查询文件中的使用位置，导入并应用已有 Shader。
- **网页导入**：通过本机浏览器捕获网页，将支持的 DOM 内容转成可编辑图层。
- **设计稿到代码**：读取语义设计上下文、CSS 与素材；索引项目组件、Token 和图标，管理本地组件与代码映射。
- **代码层读取**：读取现有 Code Layers 的外部属性。
- **脚本与批量操作**：画布脚本、批量修改、本地脚本配方、分步任务与断点续跑。
- **错误恢复**：结构化错误与修复建议、操作状态、写入日志、幂等去重、局部核查及符合条件的失败新建节点清理。
- **连接与帮助**：生成配对插件、多文件选择、断线重连、能力查询、运行状态和调用耗时；内置使用指南。
- **MCP 接入**：官方桌面与远程 MCP 连接、授权与工具发现，以及资源和提示词访问。

## 可以直接这样说

- 「读取选中的设置页，把主按钮改为 40px 高、8px 圆角，完成后给我截图。」
- 「将选中的画板绑定为设计参考，再按同一套样式新建一个页面。」
- 「解绑当前参考，换成现在选中的画板。」
- 「导出这个画板的 SVG 和 PNG，保存到当前工作区。」

插件里的「设计参考」支持手动绑定和解绑，也可交给 DSH 操作。变更会同步到下一次模型请求，不会反复注入完整画板或规范内容。

## 升级与连接排查

升级时在对应宿主/profile 再执行 `add dsh-to-figma@latest`；npm 同版本包不会随 GitHub 文档修订而更新。更新后再让 DSH 调用 `figma_setup`，保留原导入目录，关闭并重新运行 Figma 插件。通过 `figma_status` 确认两端版本一致；只更新安装包不会替换 Figma 中正在运行的旧实例。

若没有连接，先确认两端在同一台电脑、DSH 插件组件正在运行、Figma 文件中的 Local 插件窗口保持打开。遇到问题，把错误交给 DSH，并让它读取 `figma_read_guide` 的 `help-connection` 或 `help-troubleshooting`。
