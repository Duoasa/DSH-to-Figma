# 0.3.5 发布验证

验证日期：2026-11-06。对应版本：0.3.5。

## 变更范围

0.3.5 提供原生动效工作流、能力探测、使用指南、原生文件身份与重连提示，并支持素材导入导出及画布编辑。已验证 DSH Desktop 0.2.2-rc.1 兼容性。原生 Figma Specs 由编辑器实际 API 决定是否可用。

同步 package/lockfile、三语言 README、能力说明、更新记录和 16 篇内置指南。README 保留真实使用案例与录制日期；旧验证文档加注历史标识。

## 自动化与打包

- `npm run test:all`：101 项测试通过；语法、配套构建、manifest 与包文件检查通过。
- 真实 DSH 服务冒烟：固定依赖 0.2.1-rc.5，19 个本地工具；插件实际入口、原生会话、HTTP、图像附件、导出、重连通过。
- 新增回归：已有默认规范与损坏的旧配置均不注入、不阻塞写入、不被删除；四个 `/specs/` 路由均返回 404；配套启动不发送规范请求。
- 通用 ZIP 的 bootstrap 仅包含版本与端口，无配对凭证；UI 与源码一致。
- TGZ 排除 output、tmp、私有测试 home 和未跟踪的远端验证记录；不含已删除的规范存储模块和帮助章节。

通过官方桌面内置 CLI 安装 0.3.5，重启宿主，并重开真实 Figma Local 配套插件。DSH 界面与实际 `figma_status` 均确认 pluginVersion/companionVersion 为 0.3.5，featureVersion 为 4；组件运行正常，规范面板消失。

在既有实机验证文件中，通过 DSH Work 会话完成：

- 版本查询、目标绑定、任务创建、字体查询及能力刷新。
- 新建可编辑的 400×240 Auto Layout 卡片 `80:6`，标题 `80:7`、按钮 `80:8`、按钮文字 `80:9`。
- 下一次独立调用将按钮圆角从 12 改为 16；回读尺寸、布局、文案和圆角均符合要求。
- 截图与 PNG 导出成功；实际查看 800×480 PNG，标题和按钮完整可见。

## DSH 更新兼容性

通过应用内官方更新，从 0.2.1-rc.5 升级至 **0.2.2-rc.1** 并自动重启；Info.plist 与内置 CLI 均确认版本。升级后实际执行了以下检查：

- 0.3.5 插件正常加载，原 Figma 配套连接恢复；实时状态确认两端均为 0.3.5。
- 重新绑定当前连接、创建新任务，读取测试卡片；按钮圆角 16 → 20 → 16，两次改后回读均通过。
- 能力刷新、真实截图、`download_assets` PNG 导出均成功；该轮 8 个工具调用均成功。
- 人工在 Figma 窗口暂停/恢复后，旧绑定变为 `disconnected`，新连接匹配为 `same-file-key`。重选前唯一一次 metadata 调用如预期被拒绝；显式选择新连接后，卡片和按钮读取恢复，尺寸/圆角/文案保持一致。
- PNG 导出 800×480、16031 bytes；升级前后的测试卡片导出内容一致。

新版宿主实际携带 Cordis 4.1.0、Schemastery 3.19.0 和 DSH peers 0.2.2-rc.1。将 peer 声明扩展为 `4.0.x || 4.1.x` 与 `3.18.x || 3.19.x`，DSH 包范围保持不变；semver 回归检查通过，旧版固定测试宿主仍保持 0.2.1-rc.5。实际运行测试成功不等于所有准入版本均已实测。
