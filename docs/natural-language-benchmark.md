# 自然语言任务对照测试

模型自行选择工具和参数，才是在验证插件的使用策略。提示词不写 `profile`、工具名、分页参数或截图档位；同一任务的新旧版本使用完全相同的提示词、模型、推理等级和文件起点。

## 运行与记录

1. 在真实 DSH 宿主中为每次任务新建会话，固定工作目录、模型及其他插件配置。记录安装的插件版本、companion 版本和测试素材的初始状态。
2. 任务用正常语言描述目标和完成标准。只读任务不改文件；编辑任务每次从独立的相同副本开始，执行后核对内容、组件关系及变量绑定。
3. 每个版本、每个任务至少运行三次，记录每次原始结果，比较中位数和波动。交替版本或明确记录运行顺序，区分冷启动与缓存已建立的运行。
4. 从 DSH 的持久化会话日志提取实际用量，不让模型估算自己的 token。真实截图和结构回读用于检查任务正确性；错误、补读和修复产生的消耗也纳入比较。

本地日志分析脚本只读指定文件，不调用模型、不读取凭证，也不修改会话：

```sh
node scripts/analyze-dsh-session.mjs /path/to/session.v4.jsonl.zstd \
  --label '0.2.5 / known-target / run-1' \
  --output /tmp/known-target-new-1.json
```

压缩日志需要支持 `zstdDecompressSync` 的 Node 运行时，例如 DSH 随附的 Node 24。日志包含多个独立的 Zstandard frame；脚本逐帧解码并拒绝损坏或未完整写入的尾部。应在任务结束后分析。

`--turn N` 只分析指定轮次，`--after-seq N` 只分析给定事件序号之后的数据。若从一轮中间截取，报告不会把缺少起点的区间标记为完整任务。`--output` 只创建新文件，避免覆盖原始证据。

默认报告保留用量、耗时、工具名和决定读取范围的参数；不输出用户文案、模型回答、设计内容、节点 ID、查询词、文件路径或脚本正文。`--include-prompts` 仅适用于已确认可公开的合成测试提示词，发布前仍需审核。不要提交完整的用户会话日志。

单次任务可用收集器命名报告，并单独保存仅供本地正确性核对的最后回答：

```sh
node scripts/collect-natural-benchmark.mjs --version 0.2.5 --task read \
  --repeat 1 --session /path/to/session.v4.jsonl.zstd \
  --out-dir /tmp/dsh-natural-reports \
  --private-answer /tmp/dsh-natural-read-answer.txt
```

`--repeat` 是本次运行序号，不会发起模型调用。收集器要求选中一轮已成功结束且 usage 完整的任务；多轮会话需明确传入 `--turn`。版本参数只是标签，需另行核对实际安装版本。报告的 `correctness` 保持 `pending-independent-review`，直到人工或独立结构检查完成。`--private-answer` 文件包含模型回答及可能的设计内容，不能随性能报告发布。

## 指标口径

- `modelRequests`：该主会话记录的助手响应和重试尝试数量。记录到的重试用量计入总数；缺失 usage 不按零处理。
- `usage`：DSH adapter 保存的供应商用量字段，包括输入、输出和可用的缓存字段。字段保留原语义；例如当前 DeepSeek adapter 的 `inputTokens` 是未缓存输入，不能再从它减一次缓存读取。不能根据字节数推算计费 token。
- `activeWallMs`：各轮 `turn/start` 至 `turn/end` 的时长之和，不包含用户两轮之间的停留时间。
- `toolCalls` / `toolErrors`：主会话工具调用及工具错误，包含状态查询、Skill 加载等；与插件只统计画布调用的性能计数不同。
- `calls[].arguments`：仅保留 `summary/full`、深度、分页、截图开关等安全参数，以及是否提供目标 ID、查询词或脚本的布尔标记。用于判断模型是否采用按需读取。

该报告不包含会话标题生成、其他会话、子代理或后台任务的用量。若任务使用这些功能，应另行合并其来源，不能把主会话统计当成全部成本。缺失 provider usage 或未结束的任务均不能作为完整的成本验收数据。

## 判定

先确认任务正确，再比较完整成本。已知目标的任务应避免无意义的全页发现；空集合不能因为变量列表为空就被重复创建；结构任务不应重复截图；视觉任务不能通过省略必要截图来获得更低用量。单次返回变小但补读、返工或总请求增多，不算性能提升。
