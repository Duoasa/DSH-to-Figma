## 中文

DSH to Figma 0.3.5 带来原生动效、文件重连与使用指南更新，并通过 DSH Desktop 0.2.2-rc.1 兼容性验证。

- 创建与调整原生关键帧、文字入场和动画样式，继续在 Figma 时间线中编辑。
- 根据原生文件身份识别断线后的连接候选，确认目标后恢复操作；中断操作不自动重放。
- 操作前检测当前编辑器能力，明确提示未开放的 API。
- 内置连接、设计、动效和排错指南，支持离线读取。
- 更新插件图标与紧凑界面；扩展 Cordis 4.1.x 和 Schemastery 3.19.x 兼容范围。

### 安装与升级

下载 `dsh-to-figma-0.3.5.tgz` 与 `SHA256SUMS`，校验后使用当前宿主的 CLI 安装。macOS DSH Desktop：

```sh
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" \
  plugin --profile desktop add "file:/绝对路径/dsh-to-figma-0.3.5.tgz"
```

重启 DSH，调用 `figma_setup`，关闭并重新运行 Figma 中的 **DSH to Figma · Local**。通过 `figma_status` 确认两端均为 0.3.5。已导入过配套 manifest 的用户继续使用原目录。

### 附件

- `dsh-to-figma-0.3.5.tgz`：DSH 安装包。
- `DSH-to-Figma-companion-0.3.5.zip`：不含凭证的通用配套插件，手动配对备用；日常使用推荐 DSH 生成的本机已配对版本。
- `SHA256SUMS`：以上两份文件的 SHA-256 校验值。

已通过 DSH Desktop 0.2.1-rc.5 与 0.2.2-rc.1 兼容性验证。动效以当前编辑器开放的 API 为准。

## English

Version 0.3.5 adds native keyframe, text-animation and animation-style workflows, document-aware reconnect recovery, capability checks, bundled offline help and a compact companion UI.

Compatibility verified with DSH Desktop 0.2.1-rc.5 and 0.2.2-rc.1, including canvas reads/writes, screenshots, exports and reconnect recovery. Cordis 4.1.x and Schemastery 3.19.x are now admitted alongside the previous ranges. Motion depends on APIs exposed by the editor.

Install `dsh-to-figma-0.3.5.tgz` with your host's CLI, restart DSH, run `figma_setup`, then close and reopen the Local companion. Confirm both versions with `figma_status`. The standalone companion ZIP is credential-free and requires manual pairing; keep generated paired copies private.
